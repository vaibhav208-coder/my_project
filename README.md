# 🛠️ ApexPlanet Web Development Workspace — Task 1

An enterprise-grade, interactive **Developer Diagnostics Dashboard** built to verify and demonstrate the successful provisioning of a local backend development environment. This project fulfills the benchmark deliverables for **Task 1** of the Web Development Internship at ApexPlanet Software Pvt Ltd.

---

## 🚀 Live System Architecture

The environment transitions from a static setup verification page into a dynamic, reactive control panel that pulls runtime metadata straight from the local server stack.

### 💻 Key Features
*   **Dynamic Server Metrics:** Leverages native PHP engine expressions to display live server software, active runtime engine builds, and explicit local document root directory trees.
*   **Interactive UI Tab Controls:** Implements a JavaScript-driven client-side router to switch seamlessly between the **System Overview** matrix and advanced **Runtime Details**.
*   **Reactive Verification Pipelines:** Built-in interactive verification workflows that track configuration tasks dynamically.
*   **Modern Production Interface:** Styled with responsive glassmorphism elements using a utility-first Tailwind CSS design engine and high-fidelity FontAwesome developer iconography.

## 🛠️ Technology Stack & Environment Configurations

| Layer | Component | Description |
| :--- | :--- | :--- |
